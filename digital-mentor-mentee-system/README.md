# MentorBridge

A polished, responsive mentorship workspace built with Next.js and React.

## Features
- Personal mentorship dashboard and growth plan
- Searchable mentor directory and mentorship requests
- Interactive goals with browser persistence
- Session scheduling and messaging demo
- Responsive mobile navigation

All data is stored locally in the browser, so no database or environment variables are required.

## Development
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```
